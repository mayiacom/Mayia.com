# Mayia — AI Product Studio

Mayia turns an audience and topic into a tailored digital product concept, five-part content outline, editable sales page, suggested price, and five-day launch plan. Drafts are generated by OpenAI through the Responses API.

## Run locally

1. Install Node.js 20 or newer.
2. Copy `app/.env.example` to `app/.env` and add your OpenAI API key.
3. Run `npm start` from the `app` folder and open `http://localhost:3210/digital`.

Keep API keys private. The AI key stays on the server. Review generated claims and content before publishing.

## Cashfree memberships

Cashfree is the only payment integration and receives/settles membership payments under your Cashfree merchant account. The server creates recurring Cashfree subscriptions and the browser opens Cashfree's hosted subscription checkout. Mayia does not hard-code a payment-method list; Cashfree presents the methods enabled for your account and supported for recurring mandates. This does not guarantee every method Cashfree offers for one-time payments will be available for subscriptions. The Cashfree API secret must be stored in Render environment settings, never in browser code, chat, or Git.

The pricing section lets customers select India (INR) or international (USD) before checkout. The selected currency changes the displayed plan prices and is sent to the server, which creates the Cashfree subscription in that currency. Configure the four INR values (`CASHFREE_PRICE_WEEKLY`, `CASHFREE_PRICE_MONTHLY`, `CASHFREE_PRICE_STUDIO`, `CASHFREE_PRICE_ANNUAL`) and four USD values (`CASHFREE_PRICE_USD_WEEKLY`, `CASHFREE_PRICE_USD_MONTHLY`, `CASHFREE_PRICE_USD_STUDIO`, `CASHFREE_PRICE_USD_ANNUAL`) in Render. Current configured price pairs are ₹1,020/$10 weekly, ₹2,030/$20 monthly, ₹5,050/$50 Studio monthly, and ₹10,500/$100 yearly. Enable international subscriptions and accepted currencies in the Cashfree merchant account before using USD checkout. Leave `CASHFREE_ENVIRONMENT=sandbox` until each plan is verified. Switch to `production` only with Cashfree production credentials and after your merchant account has subscriptions activated.

Cashfree checkout asks the customer for name, email, and Indian mobile number before creating the subscription. The customer authorizes a recurring mandate in Cashfree checkout. Returning to Mayia does not by itself confirm that authorization succeeded. Mayia currently has no account-based paid-access controls or entitlement system, so it must not be presented as granting paid features solely on redirect.

## Deployment

The included `render.yaml` expects this folder as the repository root. In Render, create a Blueprint from the repository, set `OPENAI_API_KEY`, Cashfree sandbox credentials, the INR and USD prices, and `PUBLIC_APP_URL`. Add secrets only through Render's Environment settings. Check the service health at `/health`. To connect `mayia.com`, add it under Render **Settings → Custom Domains** and follow the DNS records Render provides.

Render's free web service may sleep while idle. Browser-local project saves do not sync across devices. See the official [Cashfree Create Subscription API](https://www.cashfree.com/docs/api-reference/payments/latest/subscription/create-subscription) and [Cashfree subscription checkout guide](https://www.cashfree.com/devstudio/preview/subs/web/checkout).
